# Installation

You install Pocket Timer with `pipx`. The command is the same on every system.

## macOS

Open a terminal and run `pipx install pocket-timer`.

## Linux

Open a terminal and run `pipx install pocket-timer`.

## Windows

Open a terminal and run `pipx install pocket-timer`.

## Next steps

Check that it worked on the [verification page](verify-installation.md). Then start your
[first session](getting-started.md#your-first-session).
